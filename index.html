controls

click a key to rebind it. esc cancels, backspace clears. mouse bindings work while the cursor is over the game. these override whatever was set in the emulator's own menu.

save states

states made with the save state button in a game land here. exported files also load through the game's load state menu.

import / export save

imports are written into the game the next time it boots, replacing its save. battery saves and memory cards from other emulators work (.srm, .sav, .mcr and the like). export grabs the save the game last wrote.
